# EEE Club of HSTU — Website

Homepage concept for the Electrical & Electronic Engineering Club at Hajee Mohammad Danesh Science & Technology University (HSTU), Dinajpur.

**Live:** https://princekhan7748.github.io/eee-club-hstu/

## What's here

- `index.html` — a single static page. No build step, no dependencies besides Google Fonts.
- The hero is a 3D toroidal coil and sine-wave field drawn on a `<canvas>` in plain JavaScript. It follows the cursor, pauses when scrolled out of view, and shows a still frame for visitors who prefer reduced motion.

## Before launch

Values in `[square brackets]` are placeholders. Replace them with real data: member counts, years, event dates, contact email and phone. Photo slots are labelled boxes.

## Run locally

Open `index.html` in a browser.
